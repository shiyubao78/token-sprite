# Token Sprite「Token 孵化桌宠」海报设计

## 目标

基于用户指定的横版原图制作一张 3:4 竖版传播海报。原图中的蛋、六只精灵、五段进化和核心光效保持不变，通过新增标题与真实卖点，让观众第一眼看懂：消耗 Token 会孵化并养大桌面精灵。

## 核心场景

- 中央发光蛋与六只元素精灵剪影制造“会孵出谁”的悬念。
- 底部五段进化链直接展示蛋到最终化形的成长过程。
- 原图作为完整横向画面嵌入竖版中央，不裁切、不拉伸、不重绘主体。
- 只向上延展深靛蓝星空、向下延展暗色魔法地面，为文案提供空间。

## 视觉风格

- 保持原图的高完成度动画电影海报质感、宏大紫蓝星云、高对比元素轮廓光和暖金色中央蛋。
- 新增区域从原图边缘取色与延展，不能出现明显拼接线。
- 三项卖点使用轻量属性徽章，避免偏工具面板的厚重卡片感。
- 氛围是神秘、温暖、有陪伴感，不做赛博朋克硬核广告，也不做恐怖孵化。
- 角色和道具必须原创，不借用现有游戏或动画 IP 的角色、标志和标志性物件。

## 构图与文案

- 画幅：3:4 竖版。
- 用户提供的横版原图是锁定画面：蛋、六只精灵、五段进化、光效和相对位置不修改、不重绘。
- 通过向上延展紫蓝星空、向下延展魔法地面组成 3:4 竖版；标题与卖点只放在新增区域，不能遮挡原图主体。
- 唯一主标题：`烧掉的每个 Token，都在孵化你的桌面精灵`
- 卖点一：`抽稀有精灵蛋` / `普通 · 稀有 · 史诗 · 传说`
- 卖点二：`看清 Token 花费` / `今日用量 · 7 天趋势 · 花费估算`
- 卖点三：`真实 Token 养成` / `自动喂养 · 五段进化 · 收集图鉴`
- 底部保障与行动入口：`数据只留本机｜让你的 Agent 安装：github.com/shiyubao78/token-sprite`
- 所有文字通过本地排版保证准确。

## 验收标准

- 三秒内能理解“消耗 Token → 孵化蛋 → 桌面精灵”的关系。
- 中央蛋仍是第一视觉焦点，六只剪影与五段进化链完整可辨。
- 手机缩略图中仍能读懂主标题、发光蛋和三个卖点标题。
- 中文逐字准确，三项卖点和 GitHub 地址完整可读。
- 与用户提供的横版原图对比时，蛋、六只精灵、五段进化和核心光效保持不变。
- 不出现品牌 Logo、乱码、无关文字或水印。
