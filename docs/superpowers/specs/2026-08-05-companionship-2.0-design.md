# 陪伴 2.0 设计：新手抽卡期 + 亲密度羁绊系统

## 背景 / 问题
1. **抽卡前期太慢、没得挑**：第一个成就「初出茅庐」要累计 1B token，轻度用户要好几天才有第二颗蛋；且普通只有 2 只（萌芽、贝壳），多抽只出重复，"集到几只、挑一只喜欢的"实现不了。
2. **化形后情绪价值断档**：精灵化形后就杵在桌面上没下文，一次性高光之后缺少持续的情感连接。

## 目标
- 前期快速让用户集到几只、挑一只**喜欢的**重点养。
- 化形不是终点，而是**关系的开始**：靠互动 + 写代码越处越亲。

---

## A. 抽卡新手期（方案 B：多给券、不强制挑）
- **新增新手成就**（低门槛、发新手券）：
  | 成就 | 条件 | 奖励 |
  |---|---|---|
  | 初次相遇 | 首次运行 / 敲下第一个 token | 新手券 ×1（秒到） |
  | 小试牛刀 | 累计 100M | 新手券 ×1 |
  | 渐入佳境 | 累计 500M | 新手券 ×1 |
  | 破壳时刻 | 孵出第一只精灵 | 新手券 ×1 |
- **新手券从"前 4 只"抽**：萌芽 / 贝壳 / 火苗 / 雷（现成图，不出新图）。稀有度感由图鉴稀有度标记 + 后期成就券体现，新手池弱化稀有度。
- 白送启动蛋保留；前期约能集到 4~5 颗，挑一只重点养（孵化器切换在养已支持，各记各的进度）。
- 老成就「初出茅庐 1B」等门槛往中期挪。所有数值实现前再定稿、可调。

## B. 亲密度 / 羁绊系统（化形后 = 关系开始；驱动 = 互动 + 写代码）
- **亲密度来源**：
  - 写代码：每新增一定 token → 亲密度 +x（核心来源，"真实劳动"变成关系变深）
  - 逗它：摸头 / 戳 / 挠痒 / 喂零食，每次 +一点，**每天有上限**（防刷）
- **只涨不掉**：关系是累积的；"几天没写会想你 / 蔫"由**心情**负责，不扣亲密度（避免断更前功尽弃）。心情 = 近期状态（现有系统），亲密度 = 关系深度（新增）。
- **羁绊等级 Lv1~Lv5，每级解锁可见回报**：
  | 等级 | 解锁 |
  |---|---|
  | Lv1 初识 | 基础互动反应 |
  | Lv2 熟络 | 主动冒泡、偶尔打招呼 |
  | Lv3 亲近 | 用你的昵称叫你 + 新待机动作（伸懒腰 / 追光标） |
  | Lv4 依赖 | 换装（帽子 / 围巾）+ 专属口头禅 |
  | Lv5 羁绊 | 纪念日特别反应 + 最暖台词 + 专属称号 |
  - 每次升级弹小庆祝："我们更亲密啦～解锁了 XX"。

## C. 具体互动清单
- **你逗它**：摸头（长按）、戳 / 挠痒（连点）、喂零食（里程碑换）、换装（等级解锁）。
- **它主动**：记名字打招呼、作息关心（久坐 / 深夜 / 久别重逢）、里程碑同庆、陪伴纪念日（7/30/100 天）、会"活"的待机小动作（哈欠 / 伸懒腰 / 追光标 / 歪头）。

## 不做 / 以后
- 现在**不出新普通精灵图**（走 A：新手券从现成 4 只抽）。以后有灵感再加新普通精灵，新手池和图鉴会自动更丰富（① 与 ② 可叠加）。

## 实现前需定稿的数值
- 各新手成就门槛与奖励数量、亲密度增速（每 X token +1、每次互动 +几、每日上限）、每级亲密度门槛、纪念日节点。
