# Token 小精灵竖版宣传海报设计

## 目标

制作一张 3:4 竖版宣传海报，让第一次看到项目的人先被“会孵出谁”的悬念吸引，再在几秒内看懂：真实 AI 编程 Token 会驱动精灵孵化、成长和收集。

## 核心创意：神秘孵化夜

- 中央是一颗正在裂开的发光精灵蛋，作为第一视觉焦点。
- 六只现有成年精灵以巨大剪影环绕，只露出轮廓、眼睛和少量属性光效，不提前揭晓全貌。
- 画面下方加入一条同一精灵的五段进化剪影：蛋 → 破壳 → 幼体 → 成长 → 化形，让成长玩法可视化。
- 剪影保留六类现有角色的识别特征：花翼、贝壳、熔岩、雷角、机甲、冰翼。
- 画面采用深蓝紫夜色、青蓝与金色能量光，呈现动画电影海报般的冒险感、期待感和可爱气质。
- 只借鉴“未知精灵剪影”的悬念手法，不复制宝可梦角色、标志、字体、道具或具体版式。

## 信息层级与文案

1. 主标题：`下一只破壳的，会是谁？`
2. 副标题：`你写下的每个 Token，都在让它长大`
3. 玩法摘要：`写代码 → 抽精灵蛋 → 五段进化 → 收进图鉴`
4. 行动指令：`对你的 Agent 说：帮我安装 github.com/shiyubao78/token-sprite`

不再展示工具名、二维码或额外功能说明。玩法摘要只作小号辅助信息，进化链负责主要解释成长玩法，行动指令负责引导安装。

文字必须逐字准确，不增加无关英文或伪文字。若生成模型无法稳定呈现中文，允许先生成无字主视觉，再用本地排版叠加准确文案。

## 构图

- 画幅：3:4 竖版，适合朋友圈、小红书和群聊传播。
- 上部：主标题与副标题，主标题使用有动画电影感的粗圆展示字体，副标题保持克制。
- 中部：发光蛋与六只剪影组成环形包围，蛋最亮，剪影从暗处显形。
- 下部：五段进化链保持完整，最底部用深色卡片承载 Agent 安装指令，并突出 GitHub 地址。
- 手机缩略图尺寸下，仍应优先识别主标题、发光蛋和六只剪影。

## 验收标准

- 一眼能感受到神秘、可爱和“等待揭晓”。
- 三秒内能看懂玩法由真实 Token 驱动，而不是普通养宠游戏。
- 六只剪影彼此可区分，并与项目现有六种成年精灵轮廓相符。
- 五段进化链从小到大、方向明确，缩略图下仍能看出成长过程。
- 中文无错字、无乱码，信息层级清楚。
- 海报正文只出现已确认的标题、副标题、玩法摘要和安装指令，不出现 Claude Code、Codex 或二维码。
- 不出现宝可梦已有角色、精灵球、官方标志或高度相似的品牌元素。
- 最终 PNG 存入项目宣传素材目录，并提供可直接预览的绝对路径。
