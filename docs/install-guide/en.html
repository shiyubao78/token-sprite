Why does macOS block it? Signing a Mac app requires Apple’s $99/year developer membership, which this project hasn’t paid for. That doesn’t make it unsafe — the entire source is public, so you can read it or build it yourself. Token Sprite runs fully locally and uploads nothing (released builds only ping GitHub to check for a newer version).
